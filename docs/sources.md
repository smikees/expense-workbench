# Official reference points

These are implementation references, not a guarantee that prices, account coverage or CLI flags will remain unchanged. Recheck at installation time; if prose and installed source disagree, verify the installed release's behaviour with a small safe test.

- Firefly documentation: https://docs.firefly-iii.org/
- Firefly releases: https://github.com/firefly-iii/firefly-iii/releases
- Importer releases: https://github.com/firefly-iii/data-importer/releases
- Docker configuration: https://github.com/firefly-iii/docker
- Importer Docker guide: https://docs.firefly-iii.org/how-to/data-importer/installation/docker/
- Enable Banking tutorial: https://docs.firefly-iii.org/tutorials/data-importer/eb/
- Importer CLI: https://docs.firefly-iii.org/how-to/data-importer/advanced/cli/
- Firefly API specification: https://api-docs.firefly-iii.org/
- Enable Banking API and authentication: https://enablebanking.com/docs/api/reference/
- ECB reference rates: https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html
- Codex skill documentation: https://developers.openai.com/codex/skills/
- Claude Code skills: https://code.claude.com/docs/en/skills
- Fluent UI icons: https://github.com/microsoft/fluentui-system-icons
- Garden icons: https://github.com/zendeskgarden/svg-icons
- Iconify catalogue: https://icon-sets.iconify.design/
- Chart.js: https://github.com/chartjs/Chart.js

The package uses those projects as dependencies rather than redistributing Firefly, its database or a bank-provider SDK. Install official releases and retain their licences. No hosted domain or bank identity is preselected.
